# Certificate Images

Place certificate images in this folder with the following naming convention:

## Naming Format
- Use lowercase letters
- Replace spaces with hyphens (-)
- Use .jpg extension

## Examples
- web-development.jpg
- android-app-development.jpg
- artificial-intelligence.jpg
- canva-design-badge.jpg
- coding-ninjas.jpg
- agile-project-management.jpg
- android-app-development-training.jpg
- hardware-workshop.jpg
- dsa-course.jpg

## Image Requirements
- Recommended size: 800x600 pixels (4:3 aspect ratio)
- Supported formats: JPG, PNG, WebP
